# Overwatch‑2 Stat Companion

**Author:** MidnightPilotPonder | **Platform:** Windows 10 / 11 only

A lightweight desktop utility that brings your Overwatch 2 performance data right to the foreground. Track real‑time hero stats, dive into recent match history, and get instant insights without leaving the game.

---

## ✨ What you get

| Feature | Description |
|--------|-------------|
| **Live Hero Dashboard** | Current win‑rate, K/D, healing, damage‑per‑minute and more for every hero you play. |
| **Match‑by‑Match Timeline** | Scroll through the last 20 matches, see score, map, team composition and personal contributions. |
| **Compact Overlay** | Optional translucent window that stays on top of any application – perfect for quick glances while you queue. |
| **Customizable Themes** | Light, dark, and a “stealth” mode that hides numbers until you hover. |
| **Export & Share** | One‑click copy of a markdown‑ready summary to paste into Discord, Reddit or a stream overlay. |
| **Zero‑Ad, Zero‑Telemetry** | All data is fetched from Blizzard’s public API and processed locally. |

## 🚀 Quick Start

1. **Sign in** with your Battle.net account (OAuth flow opens in your default browser).
2. Choose the **Overlay** layout you prefer from Settings → UI.
3. Press **Ctrl + Shift + O** while in Overwatch 2 to toggle the overlay on/off.
4. Hover over any hero icon to see a detailed breakdown of your recent performance.
